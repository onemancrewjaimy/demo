# BRAND-ON demo's

Demo-onepagers voor bedrijven met een verouderde website. Eén map per bedrijf, met `index.html` en eventueel een map `img/`.

## Werkwijze

1. Elke ronde komen de nieuwe demo's op een aparte branch (`ronde-JJJJ-MM-DD`) met een pull request.
2. Jullie bekijken de demo's en keuren ze goed of af.
3. Goedkeuren is de pull request mergen. Afgekeurde demo's worden vóór het mergen verwijderd.

Alle demo's hebben een banner "Ontwerpvoorstel van BRAND-ON", staan op `noindex` en hebben geen werkend formulier.
